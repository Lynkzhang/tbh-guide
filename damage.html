伤害结算公式

基础伤害 · 暴击 · 抗性减免 · Buff/Debuff

总览：伤害结算流程

# 最终伤害 = 基础伤害 × 暴击倍率 × 属性加成 × 抗性减免 × Buff/Debuff倍率 最终伤害 = BaseDamage × CritMultiplier × ElementalBonus × ResistanceFactor × BuffMultiplier
注：以下公式基于游戏代码结构分析（StatModInfoData、BuffInfoData、HeroInfoData）。 FLAT = 直接加值；ADDITIVE = 百分比加法叠加后统一计算；MULTIPLICATIVE = 独立乘算。

① 基础伤害

# AttackDamage = 装备基础值 + FLAT附加 + 职业基础攻击 AttackDamage = BaseEquipAtk + Σ(FLAT型词缀) + HeroBaseAtk # 然后乘以所有 ADDITIVE 百分比加法总和 AttackDamage_boosted = AttackDamage × (1 + Σ ADDITIVE%) # 再乘以每个 MULTIPLICATIVE 独立乘算 AttackDamage_final = AttackDamage_boosted × Π(1 + MULTIPLICATIVE_i%)

② 暴击结算

# 暴击判定 IsCrit = random(0,100) < CriticalChance # 暴击伤害 CritMultiplier = IsCrit ? (CriticalDamage / 100) : 1.0 # 暴击率上限 = 100%，暴击伤害无上限 # 暴击率 = 职业基础 + Σ装备词缀(CriticalChance) + 符文/技能加成
示例：术士基础暴击率50% + 装备+30% = 80%暴击率，基础暴伤1650%，暴击时造成 AttackDamage × 16.5 伤害。

③ 属性伤害（元素加成）

# 元素伤害：技能描述中 物理/火焰/冰冷/闪电/混沌 伤害 ElementalBonus = 1 + ElementDamageAddition / 100 # DamageAddition 全伤害类型加成（Buff Debuff 1061：+100 固定值） DmgAdd = Σ FlatDamageAddition # 最终技能伤害 = (AttackDamage × SkillScaling%) × ElementalBonus
Debuff 说明：
• Buff 1031：火焰伤害附加 +200（FLAT），使目标受到火焰伤害时额外承受200固定值。
• Buff 1041：闪电伤害附加 +200
• Buff 1051：物理伤害附加 +200
• Buff 1061：全伤害附加 +100

④ 抗性减免

# 抗性：目标的火/冰/雷/混沌 Resistance（来自 Debuff 降低） # Debuff 9100011~9100034：降低对应抗性 20/40/60 点 ResistanceFactor = max(0, 1 - EffectiveResistance / 100) # EffectiveResistance = 目标基础抗性 - Σ 抗性减少Debuff # 抗性可以被降到负数（对应超额伤害加成）

⑤ Buff 乘算

# Buff 105011：攻击伤害 ADDITIVE +500（即+5%，值单位为万分比还是千分比需确认） # Buff 606011：攻击伤害 MULTIPLICATIVE ×1000（即×10 或 +1000%？待确认单位） # 根据 MODTYPE 区分： BuffMultiplier = Π(1 + MULTIPLICATIVE型Buff值 / 10000) # 推测单位为 10000=100%
单位说明（推测）：游戏内属性值使用整数，1000 = 100%（千分比）或 10000 = 100%（万分比）。 Buff 1011 攻速 Debuff 值=300，减速后攻速降低 30%（推测为 1000=100%）。具体系数建议实测验证。
