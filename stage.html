宝箱掉落公式

表格里 怪物宝箱 / Boss宝箱 列括号内的数字（如 910011(160)、920011(1000)）即游戏数据中的 DropItemRate，单位 ‱（千分比）。每只怪/每个 Boss 死亡时各自独立判定一次。

① 基础掉落概率

// 普通怪掉宝箱（每只杀死的怪独立判定一次） P_怪物宝箱 = MonsterDropItemRate / 1000 // 例：1-1 关 (160) → 16% 每只怪掉一个普通宝箱 // Boss 掉宝箱（每个 Boss 独立判定一次） P_Boss宝箱 = BossDropItemRate / 1000 // 例：1-1 Boss (1000) → 100% 必掉关卡 Boss 宝箱 // 幕首领关（10/20/30… Boss 关）固定掉幕首领宝箱（930xxx），不走概率
注：分子越小越稀有 — (160)=16%、(80)=8%、(25)=2.5%。后期关卡 rate 会减小，因为高级怪每次都掉太亏，靠数量稀缺平衡。

② 加成系数（账号属性）

符文树 / 宠物 / 装备 等会给账号属性加成，掉率不是直接相加，而是乘以系数（来自 EAccountStatus）。

// 最终掉率 = 基础掉率 × (1 + Percent加成总和/100) + Flat加成 P_最终 = P_基础 × (1 + ΣDropChance*ChestPercent / 100) + ΣDropChance*Chest（直接增量，单位千分比） // 普通宝箱：受 DropChanceNormalChest（直加）+ DropChanceNormalChestPercent（乘算%）影响 // 关卡 Boss 宝箱：受 DropChanceStageBossChest + DropChanceStageBossChestPercent 影响 // 二者互不影响，分别独立计算

③ 加成来源举例

来源属性类型数值说明
符文 R101 Lv1DropChanceNormalChestPercent百分比+100%普通宝箱掉率系数 ×2
符文 R102 Lv1DropChanceStageBossChestPercent百分比+200%Boss 宝箱掉率系数 ×3

④ 计算示例

// 场景：1-3 关，普通怪 (160)，账号有 R101 + R103 满级 + 宠物1001 基础掉率 = 160 / 1000 = 16% 百分比加成 = 100 + 70×5 + 100 = +550% 最终掉率 = 16% × (1 + 5.50) = 16% × 6.50 = 104% 实际表现 = 每只怪 100% 掉 1 箱，超出部分约 4% 概率多掉 1 箱
溢出处理：当最终概率 > 100% 时，先必掉 1 个，剩余小数部分作为再次判定概率。直至超过 MaxAmountNormalChest / MaxAmountStageBossChest 上限（背包容量上限），多余的箱子直接丢失。

⑤ 宝箱内容物公式

宝箱本身只是容器，开启后按 DropInfoData.csv 的权重表抽取掉落物（DropType = EachDropOneWeight_DLCVariant）：

// 每个 ItemGroup 单独判定一次（不是从总池里抽 1 个，而是逐条 roll） P_某物品组 = Weight / Σ总权重 // HeroKeyCondition：501=猎人专属、601=屠杀者专属，不符合的英雄此条不生效 // 详细每箱含金量见 宝箱掉落页面
